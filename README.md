Hey, I'm Yeison. I study Software Development at Universidad Provincial de Ezeiza and I spend most of my time on the part of an app nobody sees: APIs, databases, auth, the services that have to keep working when the frontend changes its mind.

I also run. My half marathon went from **2:54** to **2:22** to **1:54:48** in three years, and that's pretty much how I write code too: ship it, measure it, make the next one less bad.

### What I'm on right now

- **[garmin-coach-mcp](https://github.com/Yeisonfjrd/garmin-coach-mcp)**: an MCP server that lets an AI plan a training block and write the workouts straight into Garmin Connect. I built it because I got tired of typing intervals into my watch by hand.
- Training for a 10K PR in December, with the plan above running on my own wrist.
- Getting deeper into backend architecture: how services talk to each other, and what breaks when they don't.
